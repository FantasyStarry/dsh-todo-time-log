## 生成方式

1. 从运行中的桌面端 `app.asar` 取出 `@deepseek-ai/dsh-client-ui-theme/lib/client.js` —— 这是
   `--dsw-alias-*` / `--dsw-static-*` / `--dsw-radius-*` / `--dsw-font-*` 的唯一来源。
2. jsdom 里设置 `window.__ModuleLoader__.load` 捕获模块工厂 → `factory(require('react'))` →
   `apply(fakeCtx)` 拿到 `main` 槽组件；`fetch` 换成按接口路径返回 mock 数据的实现
   （`/list`、`/projects`、`/workspaces`、`/complete`…）。
3. `react-dom/client` 真实挂载，`act()` 里按模式触发交互（点完成 / 撤销 / 切视图 / 开对话），
   再把 `#root` 的 HTML 与组件内 `<style>` 抽出来拼成独立 HTML（含主题 CSS）。
4. 无头 Chrome：`--headless=new --screenshot --window-size=1280,820`；截图前冻结 toast 与
   骨架屏动画，保证可复现。

局限：不含宿主窗口外壳（标题栏 / 侧边栏）；jsdom 没有排版引擎，所以像素尺寸断言不可靠，
预览里用的是**结构断言**（见下）。

## 附带的渲染期断言（26 + 8 + 2）

断言与截图是同一套渲染环境里的两种运行模式：`verify` / `verify-empty` / `verify-uncat` 三种模式跑下面的断言，其余模式生成预览页。断言全部通过后，再用它渲染出的 HTML 截图，所以预览里的 DOM 结构与断言覆盖的是同一份代码。

- 页头、唯一主操作（收起对话录入时 `.ttl-button-primary` 只有 1 个）、数据卡片包裹工具栏、两组分段控件；
- toast host 初始为空、位于 `.ttl-root` 下（即 `.ttl-scroll` / `.ttl-page` 之外）；
- 点「完成」出现成功 toast（成功图标 + 撤销按钮），**不新增任何 `.ttl-page` 子节点**；
- 撤销 → toast 变为「已取消完成。」且不再提供撤销；关闭 → toast 消失；
- 筛选「已完成」后表格行数 = 该分段计数；方向按钮的 `aria-label` 随之翻转；
- **分类筛选**下分段计数随之切换（3/1/2）且与行数一致，清空分类后回到全局计数；
- 四个视图各自渲染（表格 / 看板 / 甘特图 / 日历）；对话录入可开可合。

另有两个模式：`verify-empty`（8 条断言：表格/看板/甘特图/日历的空态都带出口按钮；状态筛选 + 分类筛选同时生效时一次点击全部清掉；无筛选时点击聚焦新建输入框）与 `verify-uncat`（2 条断言：选了「未分类」但没有任何未分类待办时，计数必须是 0/0/0 而不是回落到全局统计）。

六期–八期看板改版另跑了一轮 **58 条交互断言**（同一套 jsdom 真实挂载 + 真实 `client.js`、**mock 数据：4 条未完成 + 12 条已完成，含优先级与类型**）：未完成/已完成两列与计数、已完成列默认 10 条 + 「显示全部」、每卡 checkbox/更多按钮/`<time>`、更多操作展开、按分类分组（4 列 + 状态徽标）、切回状态分组、看板状态筛选生效与重置、搜索（1 条命中 / 无结果空态 / Escape 清空）、勾选完成后跨列移动与计数变化；七期新增：紧凑密度 class 切换、状态×分类泳道（≥6 个泳道）、泳道折叠/展开、「移到分类」写回 + toast + 撤销、`/` `n` `f` 快捷键、优先级徽标/卡片 select 写回 + 撤销、新建表单携带优先级、表格排序含优先级。八期新增：类型徽标（缺陷/新功能/改进/疑问/杂项/其他）、卡片类型 select 写回 + 撤销、新建表单携带类型、类型筛选、搜索命中类型名、表格类型徽标；`/todo` 草稿的 `@` 菜单候选（分类 / 优先级 / 类型）与插入文本（`#分类 ` / `!high ` / `^bug `）。截图与断言在同一份渲染结果上产生。

预览用的主题样式包含 `base` / `design_platform` / `gradient_shadow_text` / `focus` / `corner_shape` / `scrollbar` 六个块，所以 `--dsw-shadow-lv*` 也是真实值（新建卡片、选中分段、toast 的浮起效果与真机一致）。
