# 操作逻辑：三层单一入口

> 2026-11-06。本文记录「待办时间日志」面板的操作逻辑基线：为什么这样分层、每个动作的唯一控制点在哪、哪些取舍是刻意不做。改 UI 前先读一遍，避免又把入口摊平。

## 一句话

**按使用频次分三层，同类动作在全应用只保留一个控制点（聊天侧的「待办」胶囊只是镜像，不新增第二类操作）。**

| 层 | 用户意图 | 频率 | 唯一入口 |
| --- | --- | --- | --- |
| 捕获 | 想到一件事，记下来 | 最高 | 顶部 composer：输入框 +「添加」；属性靠 `#分类 @文件 !优先级 ^类型`，不靠表单。聊天侧的镜像入口是主输入框下方「待办」胶囊里的一行输入（同一条 Host 解析，见规则 5） |
| 流转 | 看还剩什么，勾掉 / 改 / 删 | 次高 | 勾选圈（完成 + 撤销）、点标题（详情）、行尾「⋯」（详情 / 编辑 / 删除）；聊天侧镜像 = 胶囊清单里勾一下（只完成，不做别的） |
| 复盘 | 这件事花了多久 | 低但差异化 | 表格完成时间列双行、看板卡片用时、甘特图生命周期、日历时间分布 |

## 已锁定的五条规则

1. **完成时间列双行**：已完成 = 完成时刻 +「用时 X」；未完成 = `-` +「进行中 X」（每 60s 随 `nowMs` 刷新）。不新增列，7 列结构不变。
2. **每行两个控制点**：勾选圈负责完成 / 取消完成（带 toast 撤销）；行尾「⋯」负责详情 / 编辑 / 删除。标题点击展开详情是快捷键，不是第二套入口。表格与看板同一套动作模型。
3. **一个捕获入口**：单条 composer 与批量对话录入共用同一位置，`批量` 是模式切换而不是第二个入口；页头不再放「对话录入」。导入 / 导出留在页头「数据」。
4. **删除 = 二次确认 + 撤销**：`⋯` → 删除先进入「确认删除 / 取消」，确认后 toast 提供撤销；撤销用 `/import`（merge）回插完整快照，id、创建时间、完成时间原样保留，不需要 Host 新增接口。
5. **主输入框旁的胶囊是「快捷镜像」，不是第二个面板**：只承担「看进行中 / 完成 / 记录」三件事，不引入编辑、删除、改分类 / 优先级 / 类型等第二类操作，也不做自己的筛选排序（清单恒为「未完成 + 创建时间升序」）。完整入口仍然只有面板一个：`打开完整面板` 一跳即到，面板是唯一完整入口。设计基线见 [quick-entry.md](quick-entry.md)。

## 工具栏

固定两行，切视图不跳位：

- 第一行：视图分段（左）+ 搜索（右）。
- 第二行：当前视图专属控件（状态筛选 / 分组 + 密度 / 甘特范围 / 日历基准 + 月份导航）+ 分类、类型筛选（右）。
- 排序只保留表头点击：工具栏的「排序」下拉与升降序按钮是同一状态的第二个控制点，已删除。

## 甘特图读数（2026-11-07）

甘特是只读时间视角，读数优先于像素：

- **轨道自适应**：标签列 200px + 轨道 flex + 用时列 84px；条形、刻度、网格全部按百分比定位，不再写死 900px，右侧时间轴与「现在」不再被裁。
- **用时列**：所有行常显 `formatDurationShort`（48 分 / 2 天 3 时）；进行中为蓝色 + 小蓝点，title 给「已进行 …」。条形只负责「什么时候发生」，时长不再靠条宽猜。
- **四档范围**：今天 / 近 7 天 / 近 30 天 / 全部；7 / 30 天按本地自然日 00:00 对齐，全部取数据首尾；「现在」固定在轨道最右，红线与用时列边框错开 2px。
- **分组折叠**：分类组头是 30px 折叠按钮，聚合「N 条 · 进行中 M · 已完成用时 X」；折叠状态放 panel state，跨视图保留。
- **明确不做**：缩放（尺度交给四档范围）、甘特内流转、截止日期。

## 明确不做

- **不做截止日期 / 逾期提醒**：产品定位是「记录」不是「计划」，加了会把操作逻辑拖回传统待办。
- **甘特 / 日历不承担流转操作**：它们是只读的时间视角，行内文字链只在紧凑视图保留。
- **看板卡片不加「详情」**：卡片已经是摘要（类型 / 优先级 / 分类 / 用时 / 文件），详情只在表格与甘特里需要。
- **不做批量完成 / 批量删除**：本地单机待办量级小，收益低于复杂度。
- **快捷镜像不做第二类操作**：胶囊清单里只有「勾掉 / 记一条」，不做行内编辑、删除、改分类 / 优先级 / 类型、拖拽，也不做已完成列表 / 历史与筛选排序；关闭路径只有「再点胶囊 / `Esc` / ×」三种，不监听 `document` 做点外部关闭（客户端产物只允许一处只读 `document.activeElement`）。
